# Croma DS 0.6.0

Developer adoption release for React 19.

Start at the hosted Storybook → Developers → Start here. Install both matching GitHub packages, import the four stylesheets and wrap the complete app in CromaProvider. React API contains 66 public component references with working examples, props, defaults and source/extension boundaries.

This release adds shared theme inheritance, exact shared colour tokens, real component controls and request/form integration recipes. Express routes and pipeline logic stay in the consuming application. Original Figma branch names, artwork and source-specific values remain distinct.

Checks run on the exact release commit. See GitHub Actions and Quality and acceptance in Storybook for their scope. Whole-system original-Figma visual acceptance, manual assistive-technology review and Croma production sign-off are not claimed. Existing releases remain unchanged.
