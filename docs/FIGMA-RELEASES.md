## Reusable release preparation

`scripts/release-figma.mjs` curates only the actual Figma packages/apps. Run `node scripts/release-figma.mjs --version 0.2.0 --prepare` to refresh the non-frozen staging copy. Preparation checks package versions, imported curated files and private-source exclusions; it does not establish build or browser success. Staging is refreshed again at freeze so ongoing source changes are included.

After an explicit source freeze and completion of `apps/figma-storybook/acceptance/current-checkpoint.json`, run `node scripts/release-figma.mjs --version 0.2.0 --freeze --checkpoint /absolute/path/to/apps/figma-storybook/acceptance/current-checkpoint.json`. The tool refuses an already frozen manifest and a pending/empty checkpoint. It refreshes staging from the frozen source, validates a clean installation/build, produces package/source/static archives, validates an extracted source install and an external React tarball consumer, then writes notes, manifest and checksums. The resulting release manifest records the actual portable-check outcomes.

Oversized downloads are split into numbered byte parts without changing assets. Reassemble them in order and verify the whole-file SHA256 before extracting. Do not upload the oversized original alongside its parts; the manifest names the uploadable files and reconstruction order. All source image/vector bytes remain intact. Version 0.1.0 remains frozen.
