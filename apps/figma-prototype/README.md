# Actual Figma DS integration example

A small React consumer of the source-derived library. It exercises a controlled FormField, native required-field validation and Button submission without component-specific CSS overrides.

The form is fictional and local. It does not send data to a service or implement a Croma business flow. Its page layout is a demonstration rather than a Figma screen reconstruction.

The integration example also exercises checkbox/switch state, radio/dropdown selection, filter toggling, accordion disclosure, keyboard tabs, popup dismissal/focus return and search submission. It uses public package imports. The narrow and wide screenshots are inspection evidence for this provisional app, not completed Croma visual-fidelity acceptance.
